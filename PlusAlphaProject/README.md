# Street Fighter EX Plus Alpha Recomp

This directory contains the configuration and tools for the USA edition (`SLUS-00548`) of Street Fighter EX Plus Alpha. The current project version is **0.2.51**.

## Playing

Run `exPlusAlpha.exe` from a build or distribution and select your own supported game disc image and **SCPH1001.BIN** BIOS in the launcher. Neither file is distributed with the project. Saves and settings are created locally.

The OpenBIOS selection has been removed from this project’s launcher.
